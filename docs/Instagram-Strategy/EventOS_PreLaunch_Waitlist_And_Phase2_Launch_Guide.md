# 🚀 PHASE 2: The Live Launch Blueprint (When Deploying to Domain)

Once your system is deployed to your production server/domain (e.g., `https://eventos.app`), execute this 4-step launch playbook.

---

## 📋 Step 2.1: Technical Pre-Flight Checklist

Before making your public launch announcement, verify:
- [ ] Production SSL Certificate active (`https://` enabled).
- [ ] Database schema migrations up-to-date.
- [ ] Authentication (`/login`, `/register`, WhatsApp OTP) tested end-to-end.
- [ ] Proposal PDF export generating correctly on server.
- [ ] Dynamic UPI / Payment gateway endpoints active.
