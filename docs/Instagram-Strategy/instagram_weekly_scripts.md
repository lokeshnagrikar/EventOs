# Instagram 1-Week Video Scripts (solo.founder.ai)

This document contains word-for-word scripts, visual directions, and audio guidelines for 5 Reels to post during your first week.

---

## 🎬 Reel 1 (Monday): The Scroll Morphing Hook
* **Goal:** Show off the premium Apple Capsule Navbar UI/UX to attract developers and tech lovers.
* **Format:** Screen recording + Text on screen.
* **Recommended Audio:** A low-fi, atmospheric tech beat (e.g., "Gymnopedie No. 1" remix or Synthwave loop).

### 📹 Video Script Flow:
1. **0:00 - 0:03 (The Hook):** 
   * *Visual:* Close-up video of the landing page at the top, showing the glass navbar. Scroll down slowly so it morphs into the floating capsule.
   * *Text on Screen:* "Building an Apple-style floating navbar..."
2. **0:03 - 0:06 (The Code):**
   * *Visual:* Quick cut to your code editor showing the Tailwind classes: `backdrop-blur-2xl bg-white/[0.03] border-white/[0.1] rounded-full`.
   * *Text on Screen:* "...with Tailwind CSS and Framer Motion."
3. **0:06 - 0:10 (The Result):**
   * *Visual:* Back to the browser, scrolling up and down rapidly to show the smooth cubic-bezier transition in action.
   * *Text on Screen:* "Rate this 1-10 in the comments! 👇 Code details in bio."

## 🎬 Reel 2 (Tuesday): The Cursor Spotlight
* **Goal:** Highlight the interactive Spotlight Cards with custom cursor-following radial glows.
* **Format:** Mobile video recording of your screen (handheld style is more authentic) + Voiceover/Text.
* **Recommended Audio:** A fast-paced tech beat.

### 📹 Video Script Flow:
1. **0:00 - 0:03 (The Hook):**
   * *Visual:* Move your mouse cursor across the bento grid cards. Show the neon glow under the cursor following the mouse path.
   * *Text on Screen:* "This UI effect took me 3 hours to perfect."
2. **0:03 - 0:07 (The Logic):**
   * *Visual:* Show the React component code where `onMouseMove` calculates the bounding box coordinates (`e.clientX - rect.left`).
   * *Text on Screen:* "Calculates mouse positions dynamically to offset a radial gradient background."
3. **0:07 - 0:10 (Call to Action):**
   * *Visual:* Zoom out to show the whole bento grid.
   * *Text on Screen:* "Follow my build-in-public journey to learn how! 🚀"
