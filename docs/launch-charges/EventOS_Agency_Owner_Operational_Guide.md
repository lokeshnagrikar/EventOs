## 📄 2.1 QUOTES & WEB PROPOSALS (`/quotes`)

### 🎯 What it does for the Owner:
Create itemized price estimates, generate interactive web proposals with 3D renderings, capture **Digital Canvas E-Signatures**, dispatch via WhatsApp, and **Save/Download PDF** documents.

### 🛠️ Step-by-Step: How to Create, Send, & Sign a Proposal

#### Step 1: Creating a Quote
1. Go to **Finance ➔ Quotes** (`/quotes`).
2. Click **`+ Create Quote`**.
3. Select Lead: *Rahul Patil*.
4. Select Proposal Template:
   - `ELEGANT` (Wedding Scenography Theme)
   - `MINIMALIST` (Corporate Summit Theme)
   - `PLAYFUL` (Gala & Birthday Theme)
5. Add Itemized Line Items:
   - *3-Day Wedding Planning & Logistics:* `₹2,00,000`
   - *Floral Scenography & Mandap Decor:* `₹1,80,000`
   - *JBL Line Array Sound & Pyrotechnics:* `₹86,101`
   - *GST Tax (18%):* `₹83,899`
   - **GRAND TOTAL:** `₹5,50,000`
6. Click **`Save Quote`** (Initial status: `DRAFT`).

#### Step 2: Sending the Web Proposal to Client
1. Open the quote details page (`/quotes/[id]`).
2. Click the primary green button: **`Send Proposal to Client`**.
3. Choose your dispatch method:
   - 🟢 **`Send via WhatsApp`**: Opens WhatsApp Web/App with pre-filled message + live web link (`https://eventos.app/quotes/share/[token]`).
   - 🔗 **`Copy Web Proposal Link`**: Copies public link to clipboard.
4. **Auto-Status Transition:** EventOS automatically updates status from `DRAFT` ➔ **`SENT`**!

#### Step 3: Downloading / Saving PDF
1. Click **`Download PDF`** in the top action bar.
2. If direct PDF URL exists, it downloads the PDF file.
3. Otherwise, EventOS formats document as `EventOS_Quote_[QuoteNumber]_[ClientName].pdf` and opens clean PDF saver!

#### Step 4: Digital Canvas E-Signing
1. Client opens the web proposal link on their phone/laptop.
2. Clicks **`Approve Proposal`**.
3. Draws their signature on the digital canvas pad and types signee name.
4. Quote status updates to **`ACCEPTED`**, triggering automatic booking promotion!

## 📊 2.2 INVOICES & ENTERPRISE PAYMENT ENGINE (`/invoices` & `/settings?tab=payment_engine`)

### 🎯 What it does for the Owner:
Generates milestone invoices and collects client payments using the **v1.2 Enterprise Payment Engine** with direct NPCI UPI QR code settlements.

### 🛠️ Step-by-Step: Setting Up Payments & Receiving Money

#### Step 1: Configure Owner Bank & UPI Settings
1. Go to **System ➔ Settings ➔ Payment Engine** (`/settings?tab=payment_engine`).
2. Enter your credentials:
   - **UPI VPA:** `agencyowner@okaxis`
   - **Account Holder:** *Royal Events & Scenography Pvt Ltd*
   - **Account Number:** `918273645012` | **IFSC:** `UTIB0000123`
3. Select **Platform Commission Mode (`feeType`)**:
   - `NO_FEE` — 0% Platform Fee (100% money clears to owner).
   - `FIXED` — Flat fee per transaction (e.g. ₹99).
   - `PERCENTAGE` — Configurable rate (e.g. 2.0% platform fee).
4. Select **Fee Bearer (`feeBearer`)**:
   - `OWNER_DEDUCTION` — Fee deducted from owner net settlement.
   - `CLIENT_SURCHARGE` — Fee added on top of client invoice total.

#### Step 2: Receiving UPI Payments
1. In Client Portal (`/portal/invoices`), client clicks **`Pay Now`**.
2. Live NPCI UPI QR code generates (`DynamicUpiQrModal.tsx`).
3. Client scans with Google Pay, PhonePe, Paytm, or BHIM and transfers ₹1,50,000.
4. Client enters UTR reference (`UPI/619283719283/GPay`), issuing an official tax receipt instantly!
